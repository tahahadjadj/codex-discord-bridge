# Support

Use GitHub Discussions for setup questions and usage help when Discussions are
enabled. Otherwise, open a GitHub issue with the **Support request** template.

Include your macOS version, Node.js version, Codex version, relevant environment
variable names with values redacted, and a short sanitized log excerpt. Never
post bot tokens, session mappings, private prompts, or local file contents.

Use private vulnerability reporting for security issues. See `SECURITY.md`.
